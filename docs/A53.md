# JARVIS no Galaxy A53 — satélite

O A53 vira um ponto de sentido e voz a mais do JARVIS: reporta presença
(bateria + GPS), encaminha SMS/notificações, e fala em voz alta no celular
quando o JARVIS manda. Também dá acesso ao painel pela PWA com push-to-talk
(botão **FALAR** usa o reconhecimento de voz do próprio Android, sem subir
áudio para o PC).

Zero APK: usa o **Termux** (grátis, código aberto) e roda um script Python
curto. Dá para instalar em 10 minutos.

## 1. No PC

1. O JARVIS gera `dados/satelite_token.txt` na primeira execução
   depois desta atualização. Guarde esse token — você vai colar no celular.
2. Para acesso de fora de casa, use Tailscale (já planejado na etapa 4):
   `tailscale serve https / http://localhost:8080`. Anote a URL HTTPS.

## 2. No A53

Instale pelo **F-Droid** (NÃO use o Termux da Play Store, que está abandonado):

- https://f-droid.org/packages/com.termux/
- https://f-droid.org/packages/com.termux.api/

Abra o Termux e rode:

```sh
pkg update -y && pkg install -y python termux-api git
termux-setup-storage
```

No Android, abra **Configurações → Apps → Termux:API → Permissões** e libere
localização, SMS e notificações conforme o que você quer encaminhar.

Clone o repositório (ou copie só a pasta `satelite/`):

```sh
cd ~
git clone https://github.com/SEU_USUARIO/JARVIS.git jarvis
```

Crie a configuração:

```sh
mkdir -p ~/.jarvis_satelite
cat > ~/.jarvis_satelite/config.json <<'EOF'
{
  "base_url": "https://SEU-TAILSCALE/",
  "token": "COLE O CONTEUDO DE satelite_token.txt AQUI",
  "nome": "a53",
  "presenca_s": 300,
  "sms": false,
  "notificacoes": false
}
EOF
```

Teste o canal:

```sh
python ~/jarvis/satelite/jarvis_satelite.py --teste
```

Se aparecer `ping OK`, suba o satélite:

```sh
python ~/jarvis/satelite/jarvis_satelite.py
```

Para subir junto com o Termux, adicione em `~/.bashrc`:

```sh
nohup python ~/jarvis/satelite/jarvis_satelite.py >/dev/null 2>&1 &
```

## 3. Push-to-talk no painel

Abra `https://SEU-TAILSCALE/mobile` no Chrome do celular, instale como app
pelo botão **INSTALAR APP** (aparece quando o Chrome permite) e use o botão
**FALAR** para dar comandos por voz. O reconhecimento é do próprio Android;
só o texto reconhecido vai para o JARVIS.

## 4. Como o JARVIS fala com o celular

As ferramentas da skill `celular` estão disponíveis para o cérebro:

- `falar_no_celular(texto)` → o A53 lê em voz alta (TTS do Android).
- `avisar_no_celular(titulo, texto)` → notificação silenciosa.

Exemplo de pedido ao JARVIS: *"Jarvis, fala no meu celular que o jantar está
pronto"* → o A53 fala **"o jantar está pronto"** mesmo com o telefone no
bolso.

## 5. Segurança

- O token mora em `dados/satelite_token.txt` (não vai pro git; o
  `.gitignore` já ignora a pasta `dados/`).
- Trocou de celular / perdeu o token? Apague o arquivo e reinicie o JARVIS:
  um novo é gerado. Reconfigure o celular com ele.
- Nunca mande o token em canais abertos. Tratamento do token é igual ao da
  chave da API: segredo local.
- `verificar_ssl: false` em `config.json` desliga a verificação do
  certificado — só use para testar em rede local com HTTPS autoassinado.

## 6. Limitações atuais

- Áudio ao vivo *do* microfone do celular *para o PC* ainda não é
  encaminhado pelo Termux (precisaria reempacotar como app). O push-to-talk
  da PWA cobre o uso principal.
- SMS/notificações são lidas por polling (120 s e 60 s). Mensagens muito
  rápidas podem passar batido no primeiro ciclo.
