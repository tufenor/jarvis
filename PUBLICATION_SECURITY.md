# Publicação segura

Esta cópia pública foi revisada antes da publicação.

- Credenciais, tokens, cookies, chaves, `.env`, logs, backups, dados de voz e configurações privadas não fazem parte do repositório.
- Endereços de rede, caminhos locais, nomes pessoais e domínios privados foram substituídos por exemplos genéricos.
- O firmware usa placeholders (`DEFINA_SEU_TOKEN` e `DEFINA_A_SENHA_DE_SETUP`); configure valores próprios somente no dispositivo local.
- Nunca envie credenciais por Issues, Pull Requests ou Discussions. Use variáveis de ambiente ou arquivos ignorados pelo Git.

Antes de usar hardware real, revise os endereços da rede local, o token do agente e a URL do relé na configuração local.
